Sobre o Projeto

O Quase Ficção é um projeto dedicado à produção, curadoria e publicação de conteúdos audiovisuais narrativos em canais próprios na plataforma YouTube.

O aplicativo Quase Ficção - Automação é uma ferramenta operacional privada, de uso estritamente interno, desenvolvida exclusivamente para automatizar rotinas de upload, agendamento e organização de vídeos do próprio canal.

Este sistema não é um serviço público nem comercial: não oferece cadastro a terceiros, não comercializa serviços e é operado exclusivamente pelos proprietários do canal.

Integração com Google OAuth

Para realizar a publicação direta de vídeos, o sistema conecta-se à API do YouTube através do protocolo seguro Google OAuth 2.0.

O acesso é restrito aos canais sob controle do operador e todos os dados de autenticação são mantidos em ambiente local seguro.
