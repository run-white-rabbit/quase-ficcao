Sobre o Projeto

O Quase Ficção é um projeto dedicado à produção, curadoria e publicação de conteúdos audiovisuais narrativos em canais próprios na plataforma YouTube.

O aplicativo Quase Ficção - Automação é uma ferramenta operacional privada, de uso estritamente interno, desenvolvida exclusivamente para automatizar rotinas de upload, agendamento de publicações e organização de metadados dos vídeos do próprio canal.

Este sistema não é um serviço público nem comercial: não oferece cadastro a terceiros, não comercializa planos ou produtos e é operado exclusivamente pelos administradores do canal.

Integração com Google OAuth e Políticas

Para realizar a publicação direta e segura de vídeos, o sistema conecta-se à API do YouTube através do protocolo Google OAuth 2.0.

O acesso é estritamente limitado aos canais sob controle do operador e todos os dados de autenticação são mantidos em ambiente local seguro, sem intermediação de servidores de terceiros.

O uso dos serviços Google obedece às diretrizes da Google API Services User Data Policy e aos Termos de Serviço do YouTube. Consulte nossos documentos regulatórios:

Política de Privacidade → Termos de Serviço →
