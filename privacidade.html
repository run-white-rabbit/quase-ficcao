Política de Privacidade

Aplicativo: Central de Publicações (Google Cloud: quase-ficcao-automacao)

Última atualização: 13 de novembro de 2026

1. Visão Geral

Esta Política de Privacidade descreve de forma transparente o tratamento de dados realizado pelo aplicativo Central de Publicações, uma aplicação de software operacional privada, de execução local e de uso estritamente interno, desenvolvida exclusivamente para gerenciar rotinas de upload, agendamento de publicações e organização de metadados em canais próprios no YouTube e em páginas próprias do mesmo operador em plataformas digitais.

O aplicativo é uma ferramenta interna e não constitui um serviço comercial, público ou plataforma para terceiros (não é SaaS). Não oferece cadastro a terceiros, não comercializa dados e não processa dados de usuários externos.

2. Uso dos Serviços de API do YouTube e Políticas Aplicáveis

A Central de Publicações utiliza os Serviços de API do YouTube (YouTube Data API v3) para realizar suas funções de integração. Ao utilizar o aplicativo em conexão com o YouTube, o sistema submete-se integralmente às seguintes políticas e diretrizes externas:

  • Termos dos Serviços de API do YouTube: https://developers.google.com/youtube/terms/api-services-terms-of-service
  • Política de Dados do Usuário dos Serviços de API do Google: https://developers.google.com/terms/api-services-user-data-policy (incluindo seus requisitos de Uso Limitado)
  • Termos de Serviço do YouTube: https://www.youtube.com/t/terms
  • Política de Privacidade da Google: https://policies.google.com/privacy

3. Dados Obtidos da API e Finalidade de Uso

A autenticação com a conta Google é realizada através do protocolo padrão Google OAuth 2.0 mediante autorização individual para cada canal próprio. Os dados acessados e obtidos através da YouTube Data API limitam-se estritamente às seguintes finalidades operacionais:

  • Autenticação e autorização: obtenção de credenciais de acesso para permitir a comunicação direta entre o script local e a API do YouTube.
  • Identificação do canal: consulta do identificador único (channel ID) e título do canal via escopo https://www.googleapis.com/auth/youtube.readonly, exclusivamente para validar se a conta autorizada corresponde ao canal correto antes de qualquer postagem, evitando envios acidentais.
  • Envio de vídeos: upload de arquivos audiovisuais, definição de títulos, descrições, tags, idioma e configuração de miniaturas (thumbnails) via escopo https://www.googleapis.com/auth/youtube.upload.
  • Consulta de resultados: verificação da resposta imediata da API do YouTube (identificador do vídeo criado e confirmação de processamento) para registro local do status de publicação.

Nenhum outro serviço da Google (como Gmail, Google Drive, contatos ou histórico de navegação) é acessado, consultado ou manipulado.

4. Armazenamento, Retenção e Exclusão de Tokens e Registros Locais

O tratamento e a guarda de dados e credenciais seguem as seguintes regras:

  • Armazenamento estritamente local: Os tokens de acesso (access tokens) e de renovação (refresh tokens) são armazenados exclusivamente no computador local do titular, em arquivos individuais por canal. O acesso é restrito através das permissões de arquivo do sistema operacional (permissões 0600, exclusivas do usuário local). Não há implementação de criptografia adicional sobre esses arquivos.
  • Sem intermediários externos: O tráfego de dados e arquivos de vídeo ocorre diretamente entre a máquina do operador e os servidores seguros da Google. Nenhum token ou dado é enviado para servidores intermediários, bancos de dados em nuvem ou serviços de terceiros.
  • Período de retenção: Os tokens de autorização permanecem armazenados localmente até que sejam revogados na Conta Google ou excluídos manualmente pelo operador. Os registros e metadados locais de publicação são mantidos no ambiente local até sua exclusão manual.
  • Exclusão manual de tokens e registros: O titular pode apagar permanentemente os tokens a qualquer momento excluindo os respectivos arquivos locais de credenciais (arquivos JSON na pasta local de segredos da aplicação) e os arquivos de registros de postagens em seu computador.

5. Não Compartilhamento, Não Comercialização e Não Uso para Publicidade ou IA

Em estrita conformidade com o funcionamento real da aplicação:

  • Ausência de venda de dados: Os dados obtidos a partir das APIs do Google nunca são vendidos, alugados, cedidos ou transferidos a terceiros sob nenhuma hipótese.
  • Sem uso para publicidade: Os dados obtidos não são utilizados para exibição de anúncios, segmentação publicitária ou marketing direcionado.
  • Sem uso para treinamento de modelos de inteligência artificial: Nenhuma informação ou conteúdo acessado através das APIs do Google é utilizado para treinar modelos de inteligência artificial ou de aprendizado de máquina públicos ou de terceiros.
  • Sem rastreamento: Este site e o sistema operacional não utilizam cookies analíticos, rastreadores de terceiros ou ferramentas de telemetria comportamental.

6. Como Revogar a Autorização

O acesso concedido à Central de Publicações pode ser revogado a qualquer momento pelo titular da Conta Google:

  1. Acesse a página de segurança e permissões de sua Conta Google: https://myaccount.google.com/permissions
  2. Localize o aplicativo Central de Publicações na lista de conexões autorizadas.
  3. Clique em Remover o acesso (ou Excluir conexões que você tem com Central de Publicações).

Após a revogação na Conta Google, o token armazenado localmente torna-se imediatamente inválido para qualquer nova requisição à API. O titular pode também remover o arquivo local de credenciais em seu computador para eliminar qualquer registro remanescente.
